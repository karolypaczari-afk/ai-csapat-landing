Frequently asked questions

Do I need a Claude account?

Yes. The specialists come in Claude skill format. Claude's free tier is enough for many tasks; for heavier use, Claude Pro or Claude Code is recommended. Cowork and the Claude Code CLI are both supported.

Does it work with both Claude and ChatGPT?

Yes - the specialists work with both Claude and ChatGPT. We built them on Claude because that's where the specialist experience is best, but you're not locked in: ChatGPT (and Codex) can convert our specialists to work there too, on their own. If you use ChatGPT or Codex and get stuck, the Training + Consultation package includes hands-on help to set it up for you.

What if I can't install it?

Every lesson includes two kinds of guide: a simple upload to Cowork, and a command for Claude Code. If you get stuck, there's an illustrated walkthrough. And in the Consultation package we set it up together with you.

Is it really in Hungarian?

Yes. Each specialist works inside your own AI (Claude or ChatGPT), which understands and replies in Hungarian. The training material, examples and guides are all in Hungarian, tuned to the Hungarian market.

Is there Hungarian customer support?

Yes. If you get stuck with anything - installation, usage, billing - you can write to us in Hungarian and we'll help in Hungarian. And in the Training + Consultation package we sit down with you in person to get started.

Claude's free tier gives you a limited number of messages - enough for many tasks. For more, Claude Pro (about 7,800 Ft / month) or Claude Code is recommended. You pay this directly to Anthropic; it's not part of the course price.
